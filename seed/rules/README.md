# Workspace rules

This directory holds small, durable pointers that explain how this workspace is
organized and where reusable tooling lives. It is not a plugin installation
directory and does not hold copied agent skills or stateful project data.

Files here are created once by the workstation bootstrap and then preserved.
Edit them locally as your working conventions mature.

| File | Purpose |
|---|---|
