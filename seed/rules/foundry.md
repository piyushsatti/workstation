# Foundry

Foundry is the compiler and template for agent plugins. It is not a set of
plugins to install wholesale.

| Location | Value |
|---|---|
| Canonical source | `https://github.com/piyushsatti/foundry.git` |
| Expected Studio checkout | `~/Studio/Developer/agents/foundry/foundry` |
| Local purpose | Build or inspect a deliberately selected agent plugin |

This workstation bootstrap does not clone, build, install, or enable Foundry.
Use Foundry only when you have chosen a specific plugin and harness target.
